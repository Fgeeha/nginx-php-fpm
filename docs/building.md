## Сборка из исходников

Требуются Docker с Buildx и GNU Make. Из корня репозитория:

```sh
make help
make check
```

`make check` собирает образ `nginx-php-fpm:local` и проверяет версии PHP и
Alpine, расширения PHP, конфигурации Nginx и PHP-FPM, Composer, Certbot,
выполнение PHP через HTTP, статический файл и ответ 404.
Проверки запускаются с OPcache и с его отключением через `OPcache=1`.
Также выполняются 16 изолированных сценариев совместимости: настройки PHP,
Xdebug, UID/GID, Git, Composer, заголовки, пользовательский Nginx-конфиг,
startup-скрипты, HTTPS и Lua/NDK. Внешняя сеть в тестовых контейнерах отключена.

Для отдельных шагов используйте `make build`, `make test` и `make test-compat`.
Имя образа можно задать через `make check IMAGE=nginx-php-fpm:latest`.

По умолчанию собирается архитектура Docker-хоста. Для другой архитектуры:

```sh
make check PLATFORM=linux/arm64 IMAGE=nginx-php-fpm:arm64
```

При сборке ARM64 на AMD64 требуется QEMU/binfmt. Тесты запускают собранный
образ, поэтому эмуляция нужна и для проверок.

Для проверки исходников портала:

```sh
make test-portal IMAGE=nginx-php-fpm:local APP_DIR=/path/to/php-project
```

Этот тест рассчитан на структуру портала: проверяет все PHP-файлы, страницы,
статику и API-прокси с локальными заглушками CMS/API. Исходники подключаются
только для чтения и копируются в одноразовый контейнер без `.env`.
Хеши HTTP-ответов позволяют сравнить старый и новый образы. Тест не заменяет
проверку рабочего сервера с его конфигурацией и внешними сервисами.

Базовый образ — `php:8.2.35-fpm-alpine3.24`. PHP 8.2.35 исправляет
CVE-2026-109618 и CVE-2026-109619:
[официальная рекомендация PHP](https://www.php.net/archive/2026.php).
После сборки необходимо пересоздать работающие контейнеры из нового образа.

Результаты и ограничения обновления: [патчноут](patchnotes/php-8.2.35.md).
